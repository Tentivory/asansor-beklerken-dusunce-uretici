# Asansör Beklerken Düşünce Üretici

> Resmi olmayan, bilimsel olmayan, asansör firmalarının onaylamadığı bir cihaz.

Bu depo, insanın asansör kapısının önünde geçirdiği o 7 ile 40 saniye arasındaki boşluğu doldurmak için kurulmuştur. Boşluk doldurulmazsa insan, komşunun poşetine bakmaya başlar. Bu, medeniyetin sonudur.

## Ne işe yarar

`python3 asansor.py` çalıştığında program:

1. Rastgele bir kat seçer (zemin hariç, zemin şüphelidir).
2. Asansörün gelme süresini abartır.
3. Bu sürede beynin üreteceği düşünceyi üretir.
4. Düşünceyi damgalar.
5. Asansör yine gelmez. Bu bir özelliktir, hata değil.

## Kurulum

Kurulum yoktur. Python 3 vardır. Varsa çalışır. Yoksa asansör merdivendir, merdiven de bir çeşit asansördür, sadece daha dürüst.

```bash
python3 asansor.py
python3 asansor.py --kat 7 --acele
```

`--acele` bayrağı asansörü hızlandırmaz. Sadece düşünceleri daha sinirli yapar. Hayat böyledir.
